## [Unreleased]

### Added

- Initial release of PTL (Probabilistic Type Lattice)
- Core Bayesian type inference engine
- Type lattice with subtyping relationships
- Default prior databases for JavaScript/TypeScript patterns
- CLI tool with analyze, report, and check commands
- VS Code extension with inline type hints
- Web playground for interactive exploration
- VitePress documentation site

### Core Features

- Confidence intervals for all type inferences
- Alternative type suggestions with probabilities
- Naming pattern recognition for common conventions
- Usage-based type evidence collection
- Incremental analysis support

### Prior Databases

- Built-in JavaScript/TypeScript priors
- React component pattern priors
- Node.js callback pattern priors
- DOM API type priors
